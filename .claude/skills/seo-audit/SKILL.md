# Skill: SEO Audit
Use this skill to inspect organic search readiness.

## Audit Workflow
1. Verify `/sitemap.xml` contains all active public URLs.
2. Verify `/robots.txt` disallows `/admin` and allows public routes.
3. Validate schema.org markup using JSON-LD (`Organization`, `Service`, `TechArticle`).
