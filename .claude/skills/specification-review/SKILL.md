# Skill: Specification Review
Use this skill to audit specifications in `specs/`.

## Evaluation Criteria
- Does the spec have clear problem statements and user stories?
- Are acceptance scenarios written in Given-When-Then format?
- Are edge cases (null values, timeouts, duplicate requests) addressed?
- Are security and privacy constraints explicitly declared?
- Does it align with `constitution.md`?
